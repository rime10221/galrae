# 갈래 · 경우의 수 트레이너

문제를 만나면 먼저

> 이 문제는 **산부인과 › 임신의 내외과적 질환** 에 속하고,
> 그 안의 *당뇨병 / 감염 / 소화·신장·비뇨기 / 순환·호흡기 / 내분비 및 기타* 중 **임신과 당뇨병** 파트다.
> 여기서 외울 것은 ~~ 이다!

를 떠올리는 공부법을 훈련하는 앱입니다. 설치 없이 브라우저에서 돌아가고(PC·모바일), Google Drive로 기기 간 동기화됩니다.

## 기능

| 화면 | 내용 |
|---|---|
| **트리** | 과목 › 대단원 › 중단원… 갈래를 워크플로위처럼 편집. `Enter` 새 항목, `Tab`/`Shift+Tab` 들여·내어쓰기, `Alt+↑↓` 순서 이동, 빈 항목에서 `Backspace` 삭제(되돌리기 가능). ●를 누르면 **외울 것**(마크다운)과 **문제 단서** 편집 |
| **트레이닝** | 범위(여러 갈래 선택 가능) + 레벨(깊이)을 정하면 그 안에서 카드가 무작위로 나옴. 프리셋 저장 가능 |
| **그래프** | 마인드맵 정렬(가장 큰 갈래가 맨 왼쪽, 하위로 갈수록 오른쪽 열, 형제는 위→아래 순서, 대단원 가지별 색) / 자유(물리) 배치, 숙련도색, 깊이 제한, 주변만 보기, `[[링크]]`는 점선 연결 |
| **홈** | 오늘 복습할 카드, 빠른 20장, 과목별 학습 범위·숙련도, 연속 학습일 |

### 트레이닝 모드

- **종합**: 단서나 제목을 보고 ① 분류 경로 ② 같은 층의 경우의 수 ③ 외울 것을 떠올림 → 정답에서 경로를 사다리 모양으로 보여주고, 각 층의 형제 갈래를 함께 표시
- **하위 펼치기**: "이 갈래 안에 무엇무엇이 있나?" — 개수만큼 빈칸이 나오고 하나씩 눌러 확인
- **위치 찾기**: 항목 이름만 보고 상위 경로를 떠올리기
- **내용 회상**: 외울 것 속 `==강조==` 부분이 빈칸으로 가려짐
- **문제 → 분류**: 적어둔 문제 단서를 보고 어느 갈래인지 판단
- **섞기**: 카드마다 모드를 무작위로

평가: **다시(1) / 애매(2) / 알았음(3)** → 간격 반복(10분 · 1일 · 3일 · 7일 · 16일 · 35일). '다시'는 세션 안에서 몇 장 뒤에 다시 나옵니다. `Z` 되돌리기, 모바일은 정답을 본 뒤 오른쪽으로 밀면 알았음, 왼쪽은 다시.

### 텍스트 가져오기 형식

교재 목차나 정리 노트를 그대로 붙여넣으면 됩니다. 들여쓰기(탭/스페이스) 또는 `#` 제목과 `-` 목록으로 계층을 만들고, `>`로 시작하는 줄은 바로 위 항목의 외울 것, `?`는 문제 단서입니다. 같은 이름이 이미 있으면 합쳐집니다.

```
# 산부인과
## 임신의 내외과적 질환
- 임신과 당뇨병
	> - 선별: 24~28주 ==50g GCT==
	? 임신 26주 산모, 50g GCT 1시간 혈당 165
- 임신과 감염질환
	- B군 연쇄상구균
```

내보내기도 같은 형식이라 옵시디언 노트에 그대로 붙여 쓸 수 있습니다.

## 배포 (GitHub Pages)

Google 로그인은 HTTPS가 필요해서 GitHub Pages를 권장합니다. 빌드 과정은 없습니다.

1. GitHub에 새 저장소(예: `galrae`)를 만들고 이 폴더의 파일을 **그대로 루트에** 올립니다.
2. Settings → Pages → Branch `main`, 폴더 `/ (root)` → Save
3. 잠시 후 `https://<사용자명>.github.io/galrae/` 에서 열립니다.
4. 안드로이드 Chrome: 메뉴 → **홈 화면에 추가**. iPhone Safari: 공유 → **홈 화면에 추가**.

`package.json`, `scripts/`, `node_modules/`는 개발용이라 배포에 없어도 됩니다(올려도 동작엔 영향 없음).

## 개발

```
npm install        # 개발 도구(puppeteer-core) 설치 — 설치된 Chrome/Edge를 사용
npm run dev        # http://127.0.0.1:8765/ 개발 서버
npm test           # 헤드리스 브라우저로 트리 편집·6개 모드·되돌리기·마인드맵 정렬·병합 등 자동 점검
npm run shots      # 위 테스트 + PC/휴대폰 × 라이트/다크 스크린샷 → .shots/
npm run icons      # icons/icon.svg → PNG 아이콘 재생성
```

(로컬에서도 Google 로그인을 쓰려면 아래 원본/리디렉션에 `http://127.0.0.1:8765` 도 등록)

## Google Drive 동기화 설정

기본값으로 Amnesia와 같은 OAuth 클라이언트 ID를 씁니다. [Google Cloud Console](https://console.cloud.google.com/apis/credentials) → 해당 OAuth 2.0 웹 클라이언트에서:

- **승인된 JavaScript 원본**: `https://<사용자명>.github.io` (Amnesia 때 이미 등록돼 있으면 그대로)
- **승인된 리디렉션 URI**: `https://<사용자명>.github.io/galrae/` ← **새로 추가** (끝의 `/` 포함)

앱의 설정 → 고급에 정확한 원본/리디렉션 주소가 표시됩니다. 별도 클라이언트를 쓰고 싶으면 새로 만들어 그 ID를 설정 → 고급에 넣으면 됩니다.

- 권한은 `drive.file`(이 앱이 만든 파일만) + 이메일뿐입니다.
- 데이터는 내 드라이브 `Galrae/galrae-data.json` 하나에 저장됩니다.
- 갈래·학습 기록·프리셋을 항목별로 병합하고 더 최근(`updated`) 쪽이 이깁니다. 삭제는 `deleted: true` 표시로 전파됩니다.
- 변경 2.5초 뒤, 앱을 열 때, 다시 앱으로 돌아왔을 때 자동으로 동기화됩니다. 오프라인에서도 로컬에 저장되고, 연결되면 다시 맞춥니다.
- OAuth 앱이 '테스트' 상태면 약 7일마다 다시 로그인해야 합니다(Google 정책).
- 새 기기에서 처음 로그인하면, 손대지 않은 예시 데이터는 드라이브 데이터에 섞이지 않습니다.

## 파일 구성

```
index.html            앱 뼈대
styles.css            스타일 (라이트/다크, 모바일 반응형)
js/app.js             라우팅, 홈, 설정, 가져오기/내보내기, 빠른 찾기(Ctrl+K)
js/store.js           데이터(갈래 트리, 학습 기록, 병합, 텍스트 파서)
js/sync.js            Google Drive 동기화
js/train.js           트레이닝(카드 생성, 세션, 간격 반복)
js/outline.js         트리 편집기 + 상세 패널
js/graph.js           캔버스 그래프 엔진
js/graphview.js       그래프 화면
sw.js                 오프라인 캐시 (파일을 고친 뒤엔 CACHE 버전 문자열을 올리세요)
manifest.webmanifest  홈 화면 설치 정보
icons/                아이콘
scripts/              개발 서버, 브라우저 테스트, 아이콘 생성 (Node)
```

```js
  log:      { "YYYY-MM-DD": { n, u } },
  presets:  { [id]: { id, name, opts, created, updated, deleted? } }
}
```
